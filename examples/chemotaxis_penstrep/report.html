02 / INGEST

Bring your own paper.

Point it at any PDF. It pulls the methods, extracts a typed spec, and either produces a runnable dilution protocol or says the paper has no aqueous step it can automate — it never invents one. Verified live on the chemotaxis paper: 68 commands, 0 errors, converged in 2 iterations, dispatched.

# read a paper -> extract the spec (IR) paper2protocol ingest your_paper.pdf # or the whole pipeline, paper -> protocol -> robot: paper2protocol run your_paper.pdf --dispatch --export out/

03 / THE GATE

What the validator catches.

STATIC

apiLevel declared in both metadata and requirements, and transfers in a loop without new_tip='always' — caught before a simulation call is even spent.

ANALYZE

A well that doesn't exist on a 24-well plate (KeyError: 'A7') — only the real Protocol Engine catches it.

CONFORMANCE

A protocol that simulates perfectly but builds the wrong experiment — 20% v/v delivered where 25% was intended. Reconstructed from the command ledger, not from the code's literals (which can lie).

Its other job is honesty: it automates only the aqueous slice a pipette can actually do — the Pen-Strep dilution series — and hands off molten-agar casting, imaging, and incubation as explicit human steps, rather than pretending to automate them.

04 / OUTPUT

The protocol — real, runnable.

penstrep_dilution_ot2.py · written by Gemini, validated by the engine
# Generated live by Gemini, validated by opentrons analyze:
# result=ok, 44 commands, 0 errors  -  realized 0 / 15 / 25 % v/v

requirements = {"robotType": "OT-2", "apiLevel": "2.20"}


def run(protocol):
    reservoir = protocol.load_labware("nest_12_reservoir_15ml", "1")
    plate     = protocol.load_labware("corning_24_wellplate_3.4ml_flat", "2")
    tiprack   = protocol.load_labware("opentrons_96_tiprack_300ul", "3")
    p300 = protocol.load_instrument("p300_single_gen2", mount="left", tip_racks=[tiprack])
    # diluent (LB) -> A1/A2/A3 : 200 / 170 / 150 uL
    for well, vol in [(plate["A1"],200), (plate["A2"],170), (plate["A3"],150)]:
        p300.transfer(vol, reservoir["A2"], well, new_tip="always")
    # stock (PenStrep) -> A2/A3 : 30 / 50 uL  =  15% / 25% v/v
    for well, vol in [(plate["A2"],30), (plate["A3"],50)]:
        p300.transfer(vol, reservoir["A1"], well, new_tip="always", mix_after=(3,100))
